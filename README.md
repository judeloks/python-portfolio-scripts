# Моё портфолио: Скрипты автоматизации на Python

Привет! Здесь собраны мои учебные и практические проекты на Python, направленные на автоматизацию рутинных задач, работу с файлами и данными.

## 📂 Список проектов:

### 1. [Умный организатор файлов (File Organizer)](./file-organizer)
- **Описание:** Скрипт для автоматического сканирования и сортировки файлов по папкам (картинки, документы, архивы и т.д.) на основе их расширений.
- **Используемые модули:** `os`, `shutil`.

### 2. [Текстовый анализатор (Text Analyzer)](./text-analyzer)
- **Описание:** Консольная утилита для глубокого анализа текста: подсчет слов, символов, предложений и поиск самых частых слов с сохранением отчета.
- **Используемые модули:** `re`, `collections.Counter`.

### 3. [Конвертер валют (Currency Checker)](./currency-checker)
- **Описание:** Программа, которая получает актуальные курсы валют в реальном времени через публичное API и выполняет быстрый расчет по текущим данным.
- **Используемые модули:** `requests`, обработка JSON.
