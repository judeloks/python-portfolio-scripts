# Моё портфолио: Скрипты автоматизации на Python

Привет! Здесь собраны мои практические проекты на Python, направленные на автоматизацию рутинных задач, работу с файлами, текстом, внешними API, таблицами и безопасностью.

## 📂 Список проектов:

### 1. [Умный организатор файлов (File Organizer)](./file-organizer)
* **Описание:** Скрипт для автоматического сканирования и сортировки файлов по папкам (картинки, документы, архивы и т.д.) на основе их расширений.
* **Стек:** `os`, `shutil`.

### 2. [Текстовый анализатор (Text Analyzer)](./text-analyzer)
* **Описание:** Утилита для глубокого анализа текста: подсчет слов, символов, предложений и поиск самых частых слов с генерацией отчета.
* **Стек:** `re`, `collections.Counter`.

### 3. [Конвертер валют (Currency Checker)](./currency-checker)
* **Описание:** Программа, которая забирает актуальные курсы валют из интернета через API и производит быстрый расчет по текущим данным.
* **Стек:** `requests`, обработка JSON.

### 4. [Менеджер задач (Todo Manager)](./todo-manager)
* **Описание:** Консольное приложение для ведения списка задач с установкой приоритетов и сохранением данных в CSV-формат.
* **Стек:** `csv`, `os`.

### 5. [Генератор паролей (Password Generator)](./password-generator)
* **Описание:** Криптографически безопасная утилита для генерации сложных паролей с функцией экспорта в файл.
* **Стек:** `secrets`, `string`.
